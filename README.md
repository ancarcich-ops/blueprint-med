# Austin Lads Goldy Extravaganza 🤠⭐

A dead-simple, Splitwise-style group expense tracker with a Texas Lone Star theme.
Enter expenses on one page, see who owes who on the next. That's the whole app.

## How it works

1. **Enter Expenses** tab
   - Add the lads (names).
   - Log each expense: what it was, the amount, who paid, and who it's split between.
2. **Who Owes Who** tab
   - See the grand total and how much each person paid.
   - Get the **fewest payments** needed for everyone to settle up.

No accounts, no server, no setup. Everything is saved in your browser
(`localStorage`), so your data sticks around between visits on the same device.

## Run it

Just open `index.html` in any browser. To share it, drop the three files
(`index.html`, `style.css`, `app.js`) on any static host (GitHub Pages,
Netlify, etc.).

## Stack

Plain HTML, CSS, and vanilla JavaScript. Zero dependencies, zero build step.
